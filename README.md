# MARK-II-DATA-ANALYSIS
MARK-II — Analyze. Clean. Transform. Prepare.
# "If you're nothing without this suit, then you shouldn't have it." 
MARK-II is a hands-on Machine Learning data engineering project focused on Exploratory Data Analysis (EDA) and Data Preprocessing.

The goal is to understand the data first, then clean, transform, and prepare it properly before moving toward Machine Learning models.

🔍 What This Project Covers
Exploratory Data Analysis
Dataset exploration and structure
Univariate & bivariate analysis
Numerical and categorical feature analysis
Missing-value inspection
Identifying useful and irrelevant features
⚙️ Data Preprocessing
Feature & target separation
Train-test splitting
Missing-value imputation
One-Hot Encoding
Ordinal Encoding
Standardization with StandardScaler
ColumnTransformer
Pipeline
Data leakage prevention
🚢 Main Dataset

The current project uses the Titanic dataset to practice the complete workflow:
